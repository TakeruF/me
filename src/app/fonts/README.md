# Site font assets

These are the existing DM Sans and Noto Sans JP WOFF2 subsets emitted by the verified Next.js 16.3.0 site export on 2026-10-06. `../fonts.css` preserves that export's font weights, Unicode ranges and fallback metrics. The fonts are bundled to remove build-time dependence on Google Fonts URL formats and network availability.

Both fonts use SIL Open Font License 1.1; the upstream license texts are included here. Sources: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/notosansjp.

**시행일:** 2026년 8월 26일

Per-App Language는 TakeruF가 개발합니다. 이 방침은 앱이 정보를 처리하는 방법을 설명합니다.

## 앱이 접근하는 정보

Per-App Language는 패키지 이름, 앱 이름, 아이콘, 현재 앱별 로케일 설정, 앱이 공식적으로 선언한 언어 지원 정보를 포함하여 Android 기기에 설치된 앱 목록을 읽습니다. 이 접근은 설치된 어떤 앱이든 선택하고, 선언된 언어 지원을 이해하며, 해당 언어 설정을 확인하거나 바꿀 수 있게 하는 데 필요합니다.

Android는 설치된 앱의 전체 목록을 민감한 정보로 분류합니다. 따라서 이 앱은 사용자에게 보이고 사용자가 직접 시작하는 핵심 기능을 위해서만 `QUERY_ALL_PACKAGES`를 사용합니다. 임의의 설치 앱을 고르는 선택기는 패키지 이름을 미리 알 수 없으므로, 더 제한적인 패키지 조회로는 같은 기능을 제공할 수 없습니다.

앱은 다음 정보도 기기 내에만 저장합니다.

- 시스템 앱 표시 여부와 같은 표시 환경설정
- 앱 시작 시 설정된 앱을 식별하기 위해 적용한 패키지 이름과 로케일 태그

## 정보의 사용 방법

설치된 앱 정보와 로컬 환경설정은 앱 목록 표시, 선언된 언어 호환성 표시, 사용자가 요청한 언어 설정 작업을 수행하는 데만 사용됩니다. 언어를 적용하면 선택한 패키지 이름과 로케일 태그가 사용자가 설치하고 권한을 부여한 Shizuku 서비스로 같은 기기 안에서 전달되며, Shizuku가 요청한 Android 시스템 작업을 수행합니다.

## 데이터 수집 및 공유

Per-App Language에는 인터넷 권한이 없으며 정보를 기기 밖으로 전송하지 않습니다. 개발자는 개인 데이터나 기기 데이터를 수집, 판매 또는 공유하지 않습니다. 앱에는 광고 또는 분석 SDK가 포함되어 있지 않습니다.

Shizuku는 사용자가 선택하여 설치하고 권한을 부여하는 별도 앱입니다. Shizuku와의 통신은 기기 내에서 이루어집니다. Shizuku의 프로젝트와 문서는 [https://shizuku.rikka.app/](https://shizuku.rikka.app/)에서 확인할 수 있습니다.

## 데이터 보유 및 삭제

앱은 개발자가 운영하는 서버에 데이터를 보유하지 않습니다. 로컬 환경설정은 앱 저장소를 지우거나 앱을 제거할 때까지 기기에 남습니다. Per-App Language에서 앱별 언어 지정을 제거하면 앱의 로컬 기록에서 해당 지정을 제거하고, 해당 시스템 로케일 재정의를 초기화하도록 Android에 요청합니다.

## 보안

Per-App Language의 모든 처리는 기기 안에서 이루어집니다. Shizuku 접근에는 사용자의 명시적인 권한 부여가 필요하며, 이 권한은 언제든지 Shizuku에서 취소할 수 있습니다.

## 아동

Per-App Language는 18세 이상의 사용자를 대상으로 하며 아동을 대상으로 하지 않습니다.

## 이 방침의 변경

이 방침의 중요한 변경 사항은 시행일을 갱신하여 Per-App Language 프로젝트 페이지에 게시합니다.

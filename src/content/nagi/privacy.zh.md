# Nagi 隐私政策

最后更新：2026年10月31日

Nagi 是由 TakeruF 开发的 Android 工作空间浏览器。从 1.1.1 起，新版本仅通过 Google Play 分发。本政策也继续适用于此前通过 GitHub 和 takeruf.com 分发的 APK 版本。联系邮箱：[support@takeruf.com](mailto:support@takeruf.com)。

## 保存在设备上的信息

Nagi 将标签页、网页标题和网址、Space、收藏、书签、浏览历史、设置、网站图标缓存、Cookie 和网站存储保存在设备上。没有开发者运营的账号、云同步、广告 SDK 或开发者运营的自动崩溃报告服务。这些信息不会上传给开发者。不同 Space 共享 Cookie 和网站登录状态；Space 不是独立的隐私配置文件。

## 网页翻译与 Google ML Kit

网页翻译和语言识别通过 Google ML Kit 的 Google Translate 在设备上运行。Nagi 不会将网页正文发送给云端翻译服务或开发者。所需语言模型从 Google 下载并保存在本地，以供之后离线翻译。清除应用数据或卸载 Nagi 会移除本地模型、翻译设置和背景照片副本。

ML Kit SDK 会为模型分发、远程配置、诊断和使用情况分析与 Google 通信。根据 Google 的说明，收集内容包括设备和应用信息（如机型、操作系统、软件包名和版本）、安装或其他标识符、性能指标、API 配置、输入输出大小、功能事件及错误代码。翻译还会报告设置的源语言和目标语言，语言识别会报告识别出的语言。SDK 通信使用 HTTPS。本地处理正文不代表 SDK 不进行网络通信或不收集诊断信息。这些诊断标识符并非 Nagi 账号；Nagi 不提供账号服务，也未集成广告 ID。

Google 的处理方式请参阅 [ML Kit 数据披露](https://developers.google.com/ml-kit/android-data-disclosure)和 [Google 隐私政策](https://policies.google.com/privacy)。清除本地应用数据不会删除外部提供商已保存的记录，其保留和删除流程由对方规定。

## 新标签页背景

选择背景照片后，Nagi 会将尺寸受限的副本导入应用私有存储并在本地显示。照片不会上传给开发者，也不会发送给 ML Kit 翻译。Android 的文件选择器仅授予所选文件的访问权；应用不请求访问整个照片库。

## 隐私浏览、广告拦截和阅读模式

当 WebView 支持配置文件隔离和浏览数据删除时，隐私浏览使用独立的临时 WebView 配置文件及内存工作区。隐私浏览的历史、标签页、设置和网站图标不会保存到普通工作区。会话期间，Cookie 和网站数据可能写入隔离的磁盘存储；关闭隐私工作区时会清除这些网站数据，异常终止后遗留的配置文件会在下次冷启动时删除。隐私窗口禁用截图、最近任务预览和自动填充。下载的文件及明确复制或分享的信息仍会保留在隐私工作区之外。此模式不会向网站或网络运营商隐藏您的 IP 地址。

广告和跟踪器匹配、阅读模式文章提取均在设备上完成。过滤规则更新通过 HTTPS 连接 easylist.to 和 filters.adtidy.org；这些服务会获知连接 IP，但规则请求不包含浏览网址、Cookie 或历史。规则数据和持久的网站例外保存在本地。本次访问的暂停是临时状态，重启应用后不会恢复。阅读模式净化提取的文章 HTML 并临时保留；加载文章图片或打开链接可能连接相关网站。网页内容不会发送给开发者或 AI 服务。

## 网站、搜索和 AI 服务

打开网页或搜索时，设备会连接所选网站或搜索服务。对方可能接收 IP 地址、浏览器信息、搜索词、Cookie、表单内容和您选择上传的文件。网站图标也可能从所访问的网站获取。这些服务的数据处理受各自政策约束。“询问 ChatGPT”会将输入的问题放在网址中并打开 ChatGPT；Nagi 不会自动将当前网页内容或浏览历史发送给 AI 服务。浏览器引擎由 Android System WebView 提供，并使用 Safe Browsing 等平台安全功能。

## 按地区自动选择搜索引擎

启用地区自动选择后，Nagi 通过 HTTPS 连接 [api.country.is](https://api.country.is/)，根据连接 IP 判断国家。该服务会看到来源 IP，但请求不包含搜索词、浏览历史、精确位置或设备标识符。得到的国家和查询时间保存在本地，用于选择搜索引擎。查询失败时，可能在设备内参考移动网络、SIM 的国家或设备地区设置。您可在设置中关闭自动选择，手动选择搜索引擎。Nagi 不控制服务提供方的日志或保留期限。

## 权限与文件

网站需要时会请求摄像头、麦克风和位置权限，并需要您的许可。您允许提供给网站的数据由该网站处理。上传通过 Android 文档选择器访问您选定的文件。下载使用 Android 下载服务；部分文件可能在卸载后保留。不请求广泛文件系统访问或后台位置权限。

照片上传可在获得许可后打开Android相机，生成的JPEG保存在应用私有缓存中，并传给您选择的网站。页面生成的Blob/data文件在确认后保存到下载目录，上限为32 MB。拖动链接或图片可能将选定的URL或图片传给放置目标。密码自动填充使用您选择的Android提供方与WebView的网站表单集成；Nagi没有独立密码库或开发者运营的凭据服务。

## 不同分发渠道的更新

Google Play 版通过 Google Play 更新，不会为了 APK 更新检查连接 GitHub，也不会下载或安装 APK 来更新自身。旧 GitHub／APK 版在启动时及用户操作时检查 GitHub 发布信息。GitHub 会看到来源 IP 和包含 Nagi 版本的 User-Agent。APK 下载和安装需要用户操作，并由 Android 请求安装授权。更新请求不包含浏览历史或搜索词。

## 保留、删除与安全

本地工作空间数据保留至您通过 Nagi 或 Android 应用数据设置删除。设置中可分别清除浏览历史以及 Cookie、网站存储和网页缓存。清除网站数据会保留标签页、书签和历史。清除 Android 应用数据或卸载会删除应用专用数据；公共下载目录中的文件需单独删除。网站或服务端数据须通过对应提供方管理。Nagi 禁用 Android 应用备份。地区查询和应用更新使用 HTTPS；HTTP 网页的通信不加密。Nagi 拒绝证书错误，阻止混合内容和第三方 Cookie，但无法保证绝对安全。

## 联系与变更

联系开发者时，消息和联系方式用于回复，并按处理邮件所需时间保留。您可通过 support@takeruf.com 请求删除相关邮件。请勿发送密码或不必要的敏感信息。政策变更会在本页公布并更新日期。

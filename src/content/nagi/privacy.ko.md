# Nagi 개인정보 처리방침

최종 업데이트: 2026년 10월 10일

Nagi는 TakeruF가 개발한 Android 워크스페이스 브라우저입니다. 이 방침은 Google Play 버전과 GitHub 및 takeruf.com에서 배포하는 APK 버전에 적용됩니다. 연락처: [support@takeruf.com](mailto:support@takeruf.com).

## 기기에 저장하는 정보

Nagi는 탭, 페이지 제목과 URL, Space, 즐겨찾기, 북마크, 방문 기록, 설정, 사이트 아이콘 캐시, 쿠키와 사이트 저장소를 기기에 저장합니다. 개발자가 운영하는 계정이나 클라우드 동기화, 광고 SDK, 분석 SDK, 자동 오류 보고 서비스는 없습니다. 이 정보는 개발자에게 업로드되지 않습니다. Space 간 쿠키와 사이트 로그인 상태는 공유됩니다. 일반 Space는 독립된 개인정보 프로필이 아닙니다.

## 비공개 탐색, 광고 차단 및 읽기 모드

WebView가 프로필 분리와 탐색 데이터 삭제를 지원하는 경우 비공개 탐색은 별도의 임시 WebView 프로필과 메모리 작업 공간을 사용합니다. 비공개 방문 기록, 탭, 설정 및 사이트 아이콘은 일반 작업 공간에 저장되지 않습니다. 세션 중 쿠키와 사이트 데이터가 분리된 디스크 저장소에 기록될 수 있습니다. 비공개 작업 공간을 닫으면 해당 사이트 데이터가 삭제되며, 비정상 종료 후 남은 프로필은 다음 콜드 시작 시 삭제됩니다. 비공개 창은 스크린샷, 최근 앱 미리보기와 자동 완성을 비활성화합니다. 다운로드한 파일과 명시적으로 복사하거나 공유한 정보는 비공개 작업 공간 밖에 남습니다. 이 모드는 웹사이트나 네트워크 사업자에게 IP 주소를 숨기지 않습니다.

광고와 추적기 매칭 및 읽기 모드 기사 추출은 기기에서 처리됩니다. 필터 업데이트는 HTTPS로 easylist.to와 filters.adtidy.org에 연결합니다. 제공자는 접속 IP를 볼 수 있지만 필터 요청에 방문 URL, 쿠키 또는 기록을 포함하지 않습니다. 필터 데이터와 저장한 사이트 예외는 기기에 보관됩니다. 이번 방문의 일시 중지는 임시 상태이며 앱 재시작 후 복원되지 않습니다. 읽기 모드는 추출한 기사 HTML을 정리하여 임시로 보관합니다. 기사 이미지나 링크를 열 때 해당 사이트에 연결할 수 있습니다. 페이지 내용은 개발자나 AI 서비스에 전송하지 않습니다.

## 웹사이트, 검색 및 AI 서비스

페이지를 열거나 검색하면 기기가 선택한 웹사이트 또는 검색 서비스에 연결됩니다. 해당 서비스는 IP 주소, 브라우저 정보, 검색어, 쿠키, 입력한 양식 내용, 업로드하기로 선택한 파일을 받을 수 있습니다. 사이트 아이콘은 방문한 웹사이트에서 가져올 수 있습니다. 각 서비스의 데이터 처리에는 해당 서비스의 방침이 적용됩니다. “ChatGPT에 질문”은 입력한 질문을 URL에 포함하여 ChatGPT를 엽니다. Nagi는 현재 페이지 내용이나 방문 기록을 AI 서비스에 자동으로 전송하지 않습니다. Android System WebView가 브라우저 엔진을 제공하며 Safe Browsing 같은 플랫폼 보안 기능을 사용합니다.

## 지역에 따른 검색 엔진 자동 선택

지역 자동 선택을 켜면 Nagi는 HTTPS로 [api.country.is](https://api.country.is/)에 연결하여 접속 IP로 국가를 확인합니다. 서비스는 접속 IP를 볼 수 있지만 요청에는 검색어, 방문 기록, 정확한 위치 또는 기기 식별자를 포함하지 않습니다. 확인한 국가와 조회 시각은 검색 엔진 선택을 위해 기기에 저장합니다. 조회에 실패하면 이동통신망이나 SIM의 국가 또는 기기 지역 설정을 기기에서 참조할 수 있습니다. 설정에서 자동 선택을 끄고 검색 엔진을 직접 선택할 수 있습니다. Nagi는 제공자의 서버 로그나 보관 기간을 관리하지 않습니다.

## 권한 및 파일

사이트가 필요로 할 때 카메라, 마이크, 위치 권한을 요청하며 사용자 허용이 필요합니다. 사이트에 제공하도록 허용한 정보는 해당 사이트가 처리합니다. 업로드는 Android 문서 선택기로 선택한 파일에 접근합니다. 다운로드는 Android 다운로드 서비스를 사용하며 일부 파일은 앱을 삭제한 후에도 남을 수 있습니다. 광범위한 파일 시스템 접근이나 백그라운드 위치 권한을 요청하지 않습니다.

사진 업로드는 권한을 허용한 뒤 Android 카메라를 열 수 있습니다. 촬영한 JPEG는 앱 전용 캐시에 저장되어 선택한 웹사이트에 전달됩니다. 페이지에서 생성한 Blob/data 파일은 확인 후 다운로드에 저장되며 최대 32 MB를 지원합니다. 링크나 이미지를 드래그하면 선택한 URL 또는 이미지가 드롭 대상에 전달될 수 있습니다. 비밀번호 자동 완성은 선택한 Android 제공업체와 WebView의 웹사이트 양식 연동을 사용합니다. Nagi에는 자체 비밀번호 보관함이나 개발자가 운영하는 인증 정보 서비스가 없습니다.

## 배포 경로별 업데이트

Google Play 버전은 Google Play를 통해 업데이트됩니다. APK 업데이트 확인을 위해 GitHub에 연결하거나 자체 업데이트용 APK를 다운로드하거나 설치하지 않습니다. GitHub／APK 버전은 시작 시와 사용자 요청 시 GitHub 릴리스 정보를 확인합니다. GitHub는 접속 IP와 Nagi 버전이 포함된 User-Agent를 볼 수 있습니다. APK 다운로드와 설치에는 사용자 동작과 Android 설치 승인이 필요합니다. 업데이트 요청에 방문 기록이나 검색어를 포함하지 않습니다.

## 보관, 삭제 및 보안

기기의 워크스페이스 정보는 Nagi 또는 Android 앱 데이터 설정으로 삭제할 때까지 보관됩니다. 설정에서 방문 기록과 쿠키·사이트 저장소·페이지 캐시를 각각 삭제할 수 있습니다. 사이트 데이터를 삭제해도 탭, 북마크, 방문 기록은 유지됩니다. Android 앱 데이터 삭제 또는 앱 제거로 앱 전용 데이터가 삭제됩니다. 공용 다운로드 폴더의 파일은 따로 삭제해야 합니다. 웹사이트나 서비스의 서버 데이터는 해당 제공자를 통해 관리해야 합니다. Android 앱 백업은 비활성화되어 있습니다. 지역 조회와 앱 업데이트는 HTTPS를 사용하지만 HTTP 웹사이트의 통신은 암호화되지 않습니다. 인증서 오류, 혼합 콘텐츠와 타사 쿠키를 차단하지만 완전한 보안을 보장하지는 않습니다.

## 문의 및 변경

개발자에게 문의하면 메시지와 연락처를 답변에 사용하고 해당 문의 처리에 필요한 기간 동안 보관합니다. 관련 문의 내용의 삭제는 support@takeruf.com으로 요청할 수 있습니다. 비밀번호나 불필요한 민감 정보를 보내지 마세요. 방침 변경 시 이 페이지에 업데이트 날짜와 함께 게시합니다.

# Token Meter 1.2.9

## English

This patch makes the Codex weekly percentage reliable again and gives the update alert a focused release-notes view.

### Changes

- Select each Codex quota bucket using the timestamp inside its usage event, preventing an older session opened later from replacing the current weekly percentage.
- Do not announce a quota reset when a stale reading has the same reset deadline as the current quota.
- The update alert now embeds a dedicated, header-free page with only the offered version's notes and a compact language selector.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Token Meter updates from the menu with “Check for Updates…”. You can also unzip `TokenMeter-1.2.9.zip` and move `TokenMeter.app` to `/Applications`.

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

アプリは Developer ID で署名し、Apple の Notary Service で公証しています。更新 ZIP は Sparkle の EdDSA 署名でも検証されます。

## 中文

此补丁重新确保 Codex 每周百分比正确，并让更新提示中的发行说明更加专注易读。

### 变更内容

- 每个 Codex 配额桶现在按照用量事件内的时间戳选择，而非日志文件修改时间；稍后打开的旧会话不会覆盖当前每周百分比。
- 旧读数与当前配额具有相同重置截止时间时，不再错误发送配额重置通知。
- 更新提示现在嵌入无页眉的专用页面，仅显示所提供版本的说明和紧凑的语言切换。

### 运行环境

- macOS 14.0 或更高版本
- Apple Silicon / Intel Mac（通用二进制）

### 安装方法

可从菜单中的“Check for Updates…”更新。也可解压 `TokenMeter-1.2.9.zip`，然后将 `TokenMeter.app` 移至 `/Applications`。

应用已使用 Developer ID 签名并已通过 Apple 公证。更新 ZIP 包也通过 Sparkle 的 EdDSA 签名进行验证。

## 한국어

이 패치는 Codex 주간 백분율이 다시 정확하게 유지되도록 하고 업데이트 알림의 릴리스 노트 보기를 간결하게 만듭니다.

### 변경 내용

- 각 Codex 쿼터 버킷을 로그 파일 수정 시간이 아니라 사용 이벤트 안의 타임스탬프로 선택합니다. 나중에 연 이전 세션이 현재 주간 백분율을 덮어쓰지 않습니다.
- 이전 읽기와 현재 쿼터의 재설정 기한이 같으면 쿼터 재설정 알림을 잘못 보내지 않습니다.
- 업데이트 알림은 이제 제공된 버전의 노트와 간결한 언어 선택만 표시하는 헤더 없는 전용 페이지를 내장합니다.

### 작동 환경

- macOS 14.0 이상
- Apple Silicon / Intel Mac (Universal Binary)

### 설치 방법

메뉴의 “Check for Updates…”에서 업데이트할 수 있습니다. 또는 `TokenMeter-1.2.9.zip` 압축을 풀고 `TokenMeter.app`을 `/Applications`로 이동하십시오.

앱은 Developer ID로 서명되었으며 Apple의 공증(Notarization)을 받았습니다. 업데이트 ZIP은 Sparkle의 EdDSA 서명으로도 검증됩니다.

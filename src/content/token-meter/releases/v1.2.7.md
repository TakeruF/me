# Token Meter 1.2.7

## English

This update keeps usage and quota information separate when the same provider exposes multiple models or quota windows.

### Changes

- Separate regular Codex usage from Codex Spark 5-hour and weekly quota windows, so Spark activity no longer looks like a reset of the regular Codex quota.
- Preserve Codex usage history independently for each model, including migrations from existing sessions without duplicating past events.
- Make Claude and Copilot multi-model usage display deterministic when more than one model appears in local logs.
- Improve notification threshold and reset handling for providers with multiple quota windows.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Unzip `TokenMeter-1.2.7.zip` and move `TokenMeter.app` to `/Applications`. If you are already using Token Meter, you can update from the menu by clicking "Check for Updates…".

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

- ローカルログに複数モデルが含まれる Claude と Copilot の表示を安定させました。
- 複数のクォータ期間を持つプロバイダーで、通知のしきい値判定とリセット処理を改善しました。

### 動作環境

## 中文

此更新可在同一服务提供商包含多个模型或配额周期时，分别显示用量和配额信息。

### 变更内容

- 分开显示普通 Codex 与 Codex Spark 的 5 小时配额和每周配额，修复使用 Spark 后普通 Codex 配额看起来像被重置的问题。

- 当本地日志包含多个模型时，使 Claude 和 Copilot 的模型用量显示更加稳定。
- 改进具有多个配额周期的服务提供商的通知阈值和重置处理。

### 运行环境

- macOS 14.0 或更高版本
- Apple Silicon / Intel Mac（通用二进制）

解压 `TokenMeter-1.2.7.zip`，然后将 `TokenMeter.app` 移至 `/Applications`。如果您已在使用 Token Meter，可通过应用内的“Check for Updates…”进行更新。

应用已使用 Developer ID 签名并已通过 Apple 公证。更新 ZIP 包也通过 Sparkle 的 EdDSA 签名进行验证。

## 한국어

같은 제공업체에서 여러 모델이나 쿼터 기간을 사용하는 경우에도 사용량과 쿼터 정보를 분리해서 보여 주는 업데이트입니다.

### 변경 내용

- 일반 Codex와 Codex Spark의 5시간 쿼터 및 주간 쿼터를 분리하여, Spark 사용으로 일반 Codex 쿼터가 초기화된 것처럼 보이던 문제를 수정했습니다.
- Codex 사용 기록을 모델별로 독립적으로 보존합니다. 기존 세션을 마이그레이션할 때 과거 이벤트가 중복 기록되지 않습니다.
- 로컬 로그에 여러 모델이 포함된 Claude와 Copilot의 모델 사용량 표시를 안정화했습니다.
- 여러 쿼터 기간을 사용하는 제공업체의 알림 임계값 및 초기화 처리를 개선했습니다.

### 작동 환경

- macOS 14.0 이상
- Apple Silicon / Intel Mac (Universal Binary)

### 설치 방법

`TokenMeter-1.2.7.zip` 압축을 풀고 `TokenMeter.app`을 `/Applications`로 이동하십시오. 이미 Token Meter를 사용 중인 경우 앱 내 “Check for Updates…”를 통해 업데이트할 수 있습니다.

앱은 Developer ID로 서명되었으며 Apple의 공증(Notarization)을 받았습니다. 업데이트용 ZIP은 Sparkle의 EdDSA 서명으로도 검증됩니다.

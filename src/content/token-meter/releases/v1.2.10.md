# Token Meter 1.2.10

## English

This patch keeps Codex quota readings in chronological order and shows when the quota was actually observed.

### Changes

- Preserve the observation timestamp when restoring Codex quota readings at launch, so an older unread session cannot overwrite a newer recovered value.
- Show the time of the Codex quota log event instead of the time the file was checked. Repeated refreshes no longer make an unchanged reading appear newly updated.
- Keep newer Codex plan information when importing older session logs.
- The product introduction, release history, privacy policy, and Claude sign-in guide are available on takeruf.com.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Token Meter updates from the menu with “Check for Updates…”. You can also unzip `TokenMeter-1.2.10.zip` and move `TokenMeter.app` to `/Applications`.

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

アプリは Developer ID で署名し、Apple の Notary Service で公証しています。更新 ZIP は Sparkle の EdDSA 署名でも検証されます。

## 中文

此补丁按时间顺序保留 Codex 剩余额度，并显示额度实际记录的时间。

- 产品介绍、更新记录、隐私政策和 Claude 登录指南已在 takeruf.com 发布。

应用已使用 Developer ID 签名并已通过 Apple 公证。更新 ZIP 包也通过 Sparkle 的 EdDSA 签名进行验证。

## 한국어

이 패치는 Codex 잔여량을 시간순으로 유지하고 실제 기록된 시간을 표시합니다.

### 변경 내용

- 시작할 때 Codex 잔여량과 관측 시간을 함께 복원하여 아직 읽지 않은 이전 세션이 더 최근의 복원 값을 덮어쓰지 않도록 했습니다.
- Codex 업데이트 시간은 파일을 확인한 시간이 아니라 잔여량이 로그에 기록된 시간을 사용합니다. 같은 값을 다시 읽어도 방금 업데이트된 것으로 표시하지 않습니다.
- 이전 세션을 가져올 때 더 최근의 Codex 요금제 정보를 유지합니다.
- 제품 소개, 업데이트 내역, 개인정보 처리방침 및 Claude 로그인 가이드는 takeruf.com에서 제공됩니다.

### 작동 환경

- macOS 14.0 이상
- Apple Silicon / Intel Mac (Universal Binary)

### 설치 방법

메뉴의 “Check for Updates…”에서 업데이트할 수 있습니다. 또는 `TokenMeter-1.2.10.zip` 압축을 풀고 `TokenMeter.app`을 `/Applications`로 이동하십시오.

앱은 Developer ID로 서명되었으며 Apple의 공증(Notarization)을 받았습니다. 업데이트 ZIP은 Sparkle의 EdDSA 서명으로도 검증됩니다.

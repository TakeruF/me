# Token Meter 1.2.6

## English

This update makes the manual Claude Code sign-in and Keychain access guide fully available in all four languages supported by Token Meter.

### Changes

- Expanded the Claude Code manual sign-in guide into complete English, Japanese, Simplified Chinese, and Korean versions. Each language now covers checking the Claude Code installation, signing in with `/login`, granting macOS Keychain access, recovering after selecting Deny, and troubleshooting common errors.
- Added language links at the top of the guide and aligned button and setting names with the localized labels shown in Token Meter.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Unzip `TokenMeter-1.2.6.zip` and move `TokenMeter.app` to `/Applications`. If you are already using Token Meter, you can update from the menu by clicking "Check for Updates…".

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

# Token Meter 1.2.8

## English

This update makes Codex quota reporting consistent across the menu bar, dashboard, and refresh actions.

### Changes

- Codex Pro now always displays its weekly account quota; the shared 5-hour / weekly preference remains available for Claude Code and other Codex plans.
- Keep regular Codex quota separate from Codex Spark. You can hide Spark quota bars in Settings under Codex without changing normal Codex reporting.
- Fix a case where refreshing could show a Spark percentage as the regular Codex percentage or incorrectly send a weekly reset notification.
- When Claude token data cannot be read, show an em dash instead of a stale token value.
- The in-app update alert now opens the release notes for the offered version.

### System Requirements

- macOS 14.0 or later
- Apple Silicon / Intel Mac (Universal Binary)

### Installation

Unzip `TokenMeter-1.2.8.zip` and move `TokenMeter.app` to `/Applications`. Existing installations can update from the menu with “Check for Updates…”.

The app is Developer ID signed and notarized by Apple. The update ZIP is also verified by Sparkle's EdDSA signature.

## 中文

此更新让 Codex 配额在菜单栏、仪表板和刷新操作中的显示保持一致。

### 变更内容

- Codex Pro 现在始终显示账户的每周配额；Claude Code 和其他 Codex 方案仍可使用共通的 5 小时 / 每周设置。

- 无法读取 Claude 令牌数据时，将显示 `—`，而不是过期的令牌值。
- 应用内更新提示现在可打开所提供版本的发行说明。

### 运行环境

- macOS 14.0 或更高版本
- Apple Silicon / Intel Mac（通用二进制）

解压 `TokenMeter-1.2.8.zip`，然后将 `TokenMeter.app` 移至 `/Applications`。现有安装可从菜单中的“Check for Updates…”更新。

应用已使用 Developer ID 签名并已通过 Apple 公证。更新 ZIP 包也通过 Sparkle 的 EdDSA 签名进行验证。

## 한국어

이 업데이트는 메뉴 막대, 대시보드 및 새로 고침 작업에서 Codex 쿼터가 일관되게 표시되도록 합니다.

- Codex Pro는 이제 항상 계정의 주간 쿼터를 표시합니다. Claude Code와 다른 Codex 요금제에서는 공통 5시간 / 주간 설정을 계속 사용할 수 있습니다.

- 새로 고침 후 Spark 비율이 일반 Codex 비율로 표시되거나 주간 재설정 알림이 잘못 전송되던 문제를 수정했습니다.

- 앱 내 업데이트 알림에서 제공된 버전의 릴리스 노트를 열 수 있습니다.

### 작동 환경

- macOS 14.0 이상
- Apple Silicon / Intel Mac (Universal Binary)

### 설치 방법

`TokenMeter-1.2.8.zip` 압축을 풀고 `TokenMeter.app`을 `/Applications`로 이동하십시오. 기존 설치는 메뉴의 “Check for Updates…”에서 업데이트할 수 있습니다.

앱은 Developer ID로 서명되었으며 Apple의 공증(Notarization)을 받았습니다. 업데이트용 ZIP은 Sparkle의 EdDSA 서명으로도 검증됩니다.

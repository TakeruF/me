# anDrop 개인정보 처리방침

최종 업데이트: 2026년 11월 1일

anDrop는 **TakeruF**가 개발하고 제공합니다. 이 방침은 macOS 앱과 Finder 공유 확장 프로그램의 GitHub 배포판 및 Mac App Store로 배포하는 경우의 버전에 적용됩니다. 배포 경로별 업데이트 방식은 아래에 설명되어 있습니다.

## 파일과 주변 기기

anDrop는 Bluetooth로 주변의 호환 기기를 검색하고 로컬 네트워크로 파일을 주고받습니다. 파일 내용과 이름·크기 등의 전송 정보는 전송에 참여하는 상대 기기와 교환됩니다. 파일 전송은 개발자가 운영하는 서버를 거치지 않으며, anDrop가 파일을 TakeruF에게 자동으로 업로드하지 않습니다.

공유 이름은 주변 기기에 표시되며 기본값은 Mac의 컴퓨터 이름입니다. 검색과 연결 과정에서는 기기 식별자, 기기 유형·제조사 정보, 로컬 네트워크 주소를 사용합니다. 송신 또는 수신 기기는 전송을 완료하는 데 필요한 정보를 받습니다. 공유 이름은 설정에서 변경할 수 있습니다. Bluetooth와 로컬 네트워크 권한은 macOS가 관리합니다.

## Mac에 저장되는 정보

anDrop는 설정, 선택한 폴더의 접근 책갈피, 기기 별칭, 숨긴 기기 설정, 기억한 기기와 신뢰 기록을 Mac에 저장합니다. 신뢰 기록에는 프로토콜 발신자 ID나 전송 공개 키의 다이제스트를 사용합니다. 호환 전송에 필요한 암호화 식별 정보도 로컬에 저장합니다. 이는 Apple·Android·제조사 계정과의 페어링이 아닙니다.

로컬 전송 기록에는 기기 이름, 파일 이름, 로컬 경로, 날짜, 전송 크기와 결과가 포함될 수 있습니다. 수신 파일은 다운로드 폴더 또는 선택한 저장 폴더에 남습니다. 공유 준비나 Live Photo 변환 과정에서 앱의 저장 공간에 임시 사본을 만들 수 있으며, 변환된 파일은 요청한 작업에 따라 저장되거나 전송됩니다. 사용자 프로필을 만들기 위해 사진 보관함을 검색하지 않습니다.

## 진단과 지원

전송 문제를 조사하기 위해 개수가 제한된 최근 진단 로그와 실패 기록을 Mac에 보관합니다. 전송 단계, 오류 코드, 파일 유형·개수, 기기 제조사·유형, 앱·macOS 버전, 전송 시작 또는 실패 당시 실행 중인 Mac 앱의 이름과 번들 식별자가 포함될 수 있습니다. 앱이 생성하는 구조화된 진단 보고서에는 파일 내용·이름, 기기 이름, 네트워크 주소, 암호 키를 포함하지 않습니다.

진단 정보는 자동으로 전송되지 않습니다. 문제 보고를 선택하면 보고서가 첨부된 이메일 초안을 준비하며, 발송 전에 검토·편집·취소할 수 있습니다. **support@takeruf.com**으로 보내면 TakeruF는 이메일 주소, 본문, 첨부 파일과 사용자가 직접 추가한 정보를 받습니다. 공유하고 싶지 않은 파일이나 정보는 첨부하지 마세요. 이메일 제공업체도 자체 약관에 따라 메시지를 처리합니다.

지원 정보는 문의에 답변하고, 문제를 조사하며, anDrop를 개선하는 데 사용합니다. 해당 목적에 필요한 동안 보관하고 더 이상 필요하지 않으면 삭제합니다. 다만 법적 의무나 분쟁 해결에 필요한 경우는 예외입니다. 같은 주소로 삭제를 요청할 수 있습니다. TakeruF는 지원 정보를 판매하거나 광고에 사용하지 않습니다.

## 인터넷 연결과 배포 경로

- **GitHub 버전:** Sparkle이 업데이트 피드를 확인하고 GitHub에서 서명된 업데이트를 내려받습니다. 자동 확인과 설치는 기본적으로 켜져 있으며 설정 → 업데이트에서 끌 수 있습니다. 업데이트 요청 시 GitHub와 배포 제공업체에 공인 IP 주소, HTTP 클라이언트·버전 정보 등의 일반적인 연결 정보가 전달됩니다. 파일 내용, 전송 기록, 진단 보고서는 업데이트 요청에 첨부되지 않으며 Sparkle 시스템 프로파일링은 비활성화되어 있습니다.
- **Mac App Store 버전:** Sparkle과 GitHub 업데이트 확인을 포함하지 않습니다. 업데이트는 Apple의 개인정보 처리방침에 따라 Mac App Store에서 제공합니다. 이는 배포 구성에 관한 설명이며 App Store 출시를 알리는 내용이 아닙니다.
- **직접 여는 링크:** 이 방침, 저장소 또는 외부 링크를 열면 브라우저가 해당 사이트에 연결하여 일반적인 연결 정보를 제공할 수 있습니다. takeruf.com의 방침 페이지는 앱의 로컬 파일 전송 기능과 별개입니다.

anDrop는 광고·분석 SDK를 포함하지 않고 TakeruF에게 사용 통계를 자동으로 전송하지 않으며, anDrop 계정을 요구하지 않습니다. GitHub, Apple, 웹 호스팅 및 이메일 제공업체는 각자의 서비스에 관한 정보를 자체 방침에 따라 처리합니다. [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)과 [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)을 참고하세요.

## 보관·삭제와 사용자의 선택

설정에서 전송 기록을 지우고, 신뢰하거나 기억한 기기를 삭제하고, 별칭과 숨김 설정을 변경할 수 있습니다. 기록을 지워도 수신 파일, 신뢰 설정, 진단 파일 또는 다른 곳에 복사한 보고서는 삭제되지 않습니다. 앱의 최근 진단은 정해진 개수 제한에 따라 교체되며 무제한 보관하지 않습니다.

설정과 신뢰 기록은 변경·삭제하거나 앱 데이터를 제거할 때까지 남습니다. 앱을 제거해도 macOS 컨테이너, 환경설정, 이전 Application Support 데이터와 컨테이너 밖의 파일은 남을 수 있습니다. 나머지 로컬 데이터를 삭제하려면 먼저 anDrop를 종료하고 사용자 라이브러리에서 앱 컨테이너·환경설정과 이전 `Library/Application Support/anDrop` 데이터를 제거하세요. 필요한 수신 파일과 내보낸 보고서는 보관하고 불필요한 사본만 저장 위치에서 삭제하세요. 삭제하면 권한, 기기 신뢰와 앱의 로컬 식별 정보가 초기화될 수 있습니다. macOS 백업과 다른 기기의 사본은 별도로 관리해야 합니다.

macOS에서 파일·폴더, Bluetooth, 로컬 네트워크, 알림 권한을 철회할 수 있으며, 관련 기능이 작동하지 않을 수 있습니다. anDrop를 종료하면 검색·전송 서비스가 중지됩니다. 신뢰하는 기기의 자동 수신을 끌 수 있고, 모두 모드에서도 신뢰하지 않는 기기의 수신 요청에는 승인이 필요합니다.

App Sandbox와 파일 접근 권한은 앱 저장 공간, 다운로드 폴더와 승인한 파일·폴더로 접근을 제한합니다. 네트워크와 기기 보호에는 한계가 있으며 완전한 보안을 보장할 수 없습니다. 기억한 기기가 개인의 신원을 증명하는 것은 아닙니다.

# anDrop introduction assets

The eight `public/projects/androp-120-{recipients,sending,trusted,settings}-{en,zh}.webp` files are lossless WebP conversions of the 1.2.0 production-view captures in [TakeruF/cn-android-share](https://github.com/TakeruF/cn-android-share/tree/v1.2.0/docs/images). Chinese pages use the Chinese app UI; English, Japanese and Korean pages use the English app UI. Each image retains its original dimensions and layout. Earlier `androp-*.webp` files remain available for existing links.

These views use the production application UI with fictional device names, file names, settings and progress. They do not establish actual transfers or compatibility with every displayed manufacturer. The introduction translates captions and alternative text into all four site languages.
